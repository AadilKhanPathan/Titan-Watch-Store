# Titan Watch Store
 
A full-featured e-commerce web application for browsing and buying watches. Customers can explore collections, filter by category, add watches to their cart, and check out, while admins manage products and orders.

## Features
- 👤 Customer Features
- 🔐 User registration and login
- 🔑 JWT-based authentication
- 🌐 Google OAuth login
- 👤 User profile
- 🛍️ Browse watches by category
- 🔎 Product details
- 🏷️ Discounted product pricing
- ❤️ Featured products
- 🖼️ Product image galleries
- 📱 Responsive design
- 🚪 Secure logout
- 🛒 Shopping functionality
### 👨‍💼 Admin Features
- 🔐 Protected admin routes
- 🛡️ Role-Based Access Control (RBAC)
- ➕ Add new products
- ✏️ Manage product information
- 🗑️ Delete products
- 📦 Manage stock/inventory
- 🖼️ Upload product images
- ☁️ Cloudinary image management
- 📊 Admin dashboard
### 🔒 Authentication & Security
- JWT authentication
- Password hashing with bcrypt
- Google OAuth
- Protected API routes
- Role-based authorization
- Environment variable based secrets
- Bearer token authentication
